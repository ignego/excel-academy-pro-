# Excel Academy Pro

Site educacional estático em português com 12 aulas distribuídas em níveis básico, intermediário e avançado, 12 questões de múltipla escolha, correção automática, progresso salvo no navegador e laboratório de fórmulas ilustrativo.

## Publicação no Render

1. Extraia o ZIP e envie os arquivos `index.html`, `style.css` e `app.js` para a raiz do repositório GitHub.
2. No Render, crie um **Static Site** conectado ao repositório.
3. Configure **Build Command** como `echo "Site pronto"` e **Publish Directory** como `.`.
4. Aguarde a implantação e abra o endereço `onrender.com` exibido pelo Render.

Não há necessidade de instalar dependências. O progresso é salvo somente no navegador/dispositivo, não em um servidor. O simulador não é uma implementação completa do Excel. Não há vídeos nem certificados nesta versão inicial.
